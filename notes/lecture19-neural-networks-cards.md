Linear vs Logistic:: Linear vs logistic regression formulas and outputs? :: Linear: yhat = w.x + b with identity activation, continuous unbounded output; Logistic: yhat = sigma(w.x + b), probability of class 1 bounded 0 to 1
Logistic Regression:: What is the sigmoid function? :: sigma(a) = 1 / (1 + exp(-a)); it maps the linear score z into a probability between 0 and 1
Logistic Regression:: When is logistic regression used and what is the default decision rule? :: When the dependent variable is categorical; predict class 1 if yhat >= 0.5, else class 0
Logistic Regression:: How is logistic regression trained? :: Gradient descent minimizes the logistic loss to optimize the coefficients of z = w1x1 + ... + wnxn + b
Threshold Tuning:: Effect of raising vs lowering the classification threshold? :: Higher threshold increases precision (fewer false positives); lower threshold increases recall (fewer false negatives)
Neural Network:: Define a neural network :: A parametric function f(x; W) = yhat made of many simple units (neurons) arranged in layers; parameters W are learned from data; f is differentiable almost everywhere so W is optimized by gradient descent
Neural Network:: How do NNs change feature engineering? :: They learn representations directly from raw data (pixels, text, audio) instead of manual features like TF-IDF or edge histograms - but inputs still must be numeric, encoded, and normalized/scaled
Deep Learning:: What is deep learning and its underlying technology? :: AI that processes data in a way inspired by the brain to find patterns in pictures/text/sound; the underlying technology is the neural network
Biological Inspiration:: Brain-to-math mapping? :: Dendrites = inputs, synapse strength = weights, cell body = weighted sum + activation, axon = output
NN Structure:: Roles of input, hidden, and output layers? :: Input receives data; hidden layers process it and learn intermediate representations (depth = capacity for complexity); output produces the prediction; information flows one direction (directed acyclic graph)
Neuron Computation:: What happens inside a neuron, and which parameters are learned? :: Compute weighted sum z = w.x + b, then activation yhat = sigma(z); weights control input importance, bias shifts the output; W and b are learned iteratively to shrink the gap between yhat and true label y
History:: Key dates in NN history? :: 1943 McCulloch-Pitts first mathematical neuron; 1957 Rosenblatt perceptron; 1970s-80s first AI winter (Minsky & Papert limits); late 1980s backprop rebirth; 2000s GPU boost; 2010s+ renaissance with big data
Perceptron:: What is a perceptron and its decision rule? :: Rosenblatt 1957, simplest NN with no hidden layer for binary classification; yhat = step(w.x + b): z >= 0 predicts class 1, z < 0 predicts class 0
Perceptron:: Perceptron training rule? :: Initialize W and b; for each example compute prediction; update parameters ONLY when the prediction is wrong (perceptron learning rule), moving the decision boundary toward correct classification
Perceptron:: Limitations of the perceptron? :: Only linear decision boundaries (linearly separable data), fails on XOR, no hidden layers, sensitive to feature scaling and may not converge, binary output only
Activation Functions:: Why are activation functions needed? :: They add non-linearity between a neuron's input and output; without them a stacked multi-layer network collapses into a single linear model
Activation Functions:: Compare sigmoid, tanh, ReLU, leaky ReLU, softmax :: Sigmoid: 0 to 1 probability; tanh: -1 to 1 centered but vanishing gradient; ReLU: 0 for negatives, z for positives; leaky ReLU: small slope for negatives to avoid dead neurons; softmax: probabilities for multi-class
Training Process:: The four steps of NN training? :: 1 forward pass + loss calculation, 2 backward pass (backprop gradients via chain rule), 3 weight update W = W - learning_rate * dL/dW, 4 repeat over epochs until error is minimized
Backpropagation:: What is backpropagation? :: The algorithm that computes the gradient of the loss with respect to each weight and bias by starting at the output error and moving backward layer by layer using the chain rule
Chain Rule:: Why does backprop use the chain rule? :: A network is a composition of functions layer by layer, so the output depends on each parameter through multiple steps; multiplying layer derivatives from output back to input gives each parameter's effect on the loss
Gradients:: What do large vs small gradients mean? :: Large gradient = that weight has high impact on the error; small gradient = the weight contributes little; the gradient is the rate of change of loss w.r.t. that weight
Backprop Example:: Backprop on f(x,y,z) = (x+y)z with x=-2, y=5, z=-4? :: Forward: q = x+y = 3, f = qz = 12; backward: df/dz = q = 3, df/dq = z = -4, dq/dx = 1 so df/dx = df/dq * dq/dx = -4 (chain rule carries y's influence through q)
Worked Example:: Key numbers of the 2-2-2 sigmoid example? :: Inputs 0.05/0.10, targets 0.01/0.99: neth1 = 0.3775, outh1 = 0.5933, outh2 = 0.5969, neto1 = 1.1059, outo1 = 0.7514, outo2 = 0.7729; Eo1 = 0.2748, Eo2 = 0.0236, Etotal = 0.2984
Update Rule:: Weight update rule after computing a gradient? :: w_new = w - alpha * dE/dw (gradient descent); e.g. trace Etotal -> o1 -> neto1 -> w5, compute dE/dw5 with the chain rule, then update
NN Summary:: Strengths and weaknesses of multi-layer feed-forward networks with backprop? :: Decent classifiers, especially good on unstructured data like images; but finicky - learning rate is hard to tune and the number of hidden nodes affects output
