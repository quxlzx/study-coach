Feature Engineering:: What is feature engineering? :: The process of transforming raw data into meaningful features that ML algorithms can use effectively; better features often lead to better predictions
Feature Engineering:: Where does it sit in the pipeline and why is it needed? :: After preprocessing (cleaning, missing values, outliers) and before building the model; models don't like categorical data, struggle with columns on different scales, and are fussy in other ways
Feature Engineering:: Name the 4 common ways to apply feature engineering :: 1) Feature creation (polynomial, interaction, clustering), 2) Feature transformation (scaling, standardization, log, binning, encoding), 3) Feature selection, 4) Feature reduction (e.g. PCA, later topic)
Feature Creation:: What are polynomial features? :: Higher-order terms like x^2, x^3 added to model nonlinear relationships, e.g. house size vs price growth
Feature Creation:: What are interaction features? :: Products of two or more features (e.g. income x age) capturing how variables influence each other simultaneously rather than independently
Feature Scaling:: Why must numerical features be scaled? :: Features with larger scales (income 48,000-83,000 vs age 27-50) contribute more to distance calculations, biasing results toward those features; critical for distance/weighted-sum models like k-NN and linear regression
Min-Max Normalization:: Give the Min-Max normalization formula :: Xscaled = (X - Xmin) / (Xmax - Xmin), rescaling every feature to the fixed range [0, 1]
Min-Max Normalization:: What are the key benefits of Min-Max scaling? :: No single feature dominates, relative distances between points are preserved, and the overall distribution shape does not change
Min-Max Normalization:: What is the main limitation of Min-Max scaling? :: It is sensitive to outliers because the scaling depends strictly on min and max values; handle outliers BEFORE scaling
Min-Max Normalization:: Which sklearn class implements Min-Max scaling? :: MinMaxScaler (more efficient and faster than a custom implementation, especially on large datasets)
Standardization:: Give the standardization (z-score) formula and its result :: X' = (X - mean) / std_dev; the transformed feature has mean = 0 and standard deviation = 1
Standardization:: Which algorithms benefit from standardization and which sklearn class? :: Algorithms relying on distance calculations or gradient-based optimization (logistic regression, SVM); use sklearn StandardScaler
Standardization:: How does standardization compare to Min-Max normalization? :: Min-Max produces a smaller spread (lower standard deviations); standardization preserves the relative spread of the data and is more robust to outliers
Log Transformation:: What is the purpose of a log transformation and what are the two forms? :: To reduce skewness and make the distribution closer to normal (bell-shaped); use x' = log(x), or x' = log(x + 1) when the data contains zero values
Log Transformation:: What are the key benefits of log transforms? :: Values spread more evenly across the scale, extreme right-tail values are pulled inward reducing their impact, and data is prepared for tests assuming normality (t-test, ANOVA)
Feature Encoding:: Why must categorical features be encoded? :: Most ML algorithms require numerical inputs, not raw strings like "red" or "blue"
Label Encoding:: What is label encoding and what is its problem? :: Assigns a unique integer to each category (Nurse=0, Doctor=1...); suitable for ordinal data, but for nominal data the numbers imply a false order/importance (Teacher=3 "beats" Nurse=0)
One-Hot Encoding:: How does one-hot encoding work? :: Each category becomes its own binary column; 1 indicates presence, 0 absence, so no category is ranked higher than another; pandas: pd.get_dummies(s)
One-Hot Encoding:: What is the main downside of one-hot encoding? :: Category explosion: if there are 50 categories, the dataset gains 50 columns
Frequency Encoding:: What is frequency encoding and its pros/cons? :: Replace each category with its occurrence count (Nurse appears 3 times -> 3); pros: reduces dimensionality and captures category importance; cons: loses uniqueness when categories share the same frequency
Target Encoding:: What is target (mean) encoding and when is it used? :: Replaces each category with the mean of the target variable for that category; suited to high-cardinality categorical data in supervised learning
Probability Encoding:: What is probability (proportion) encoding? :: Replace each category with frequency / total, e.g. Nurse appears 3 times in 6 rows -> 3/6 = 0.5; use when relative proportions matter more than raw counts
Binning:: What is binning/discretization and what are the 3 types? :: Converting a continuous feature into a set of category bins; types: equal-width (same interval size), equal-frequency (same count per bin), and custom (domain-knowledge bins)
Binning:: When is manual binning used? :: When domain-specific boundaries are known beforehand and not naturally present in the data, e.g. GPA pass/fail at threshold 3.20, county boundaries, MPG -> car type
Key ML Concepts:: What is a decision boundary and what is the training objective? :: The line (2 features) or hyperplane (more) separating classes, learned during training; training is optimization: iteratively minimize a loss/cost function to find the optimal boundary; generalization = performing well on unseen data
