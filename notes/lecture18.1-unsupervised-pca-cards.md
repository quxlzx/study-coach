Dimensionality Reduction:: Definition :: Process of reducing the number of features (dimensions) in a dataset while preserving its essential information; dimensionality = number of features/columns/variables
Why Reduce Dimensions:: The 3 motivations :: 1) Redundancy: correlated features add noise (e.g. "total purchase amount" vs "number of items"), 2) Efficiency: fewer features = faster models and better performance, 3) Curse of dimensionality: higher dims = sparser data, harder patterns, overfitting risk
Curse of Dimensionality:: What happens as dimensions grow :: Adding dimensions makes the space larger and more spread out, so data becomes sparse (few points relative to space size): harder to find patterns, more computational complexity, higher overfitting risk
Hughes Phenomenon:: Effect on predictive power :: With a FIXED number of training samples, as dimensions keep increasing, predictive power first increases but after a certain point it decreases -- this is "the curse of dimensionality"
PCA:: What PCA is :: Unsupervised dimensionality-reduction technique that simplifies a large dataset into a smaller one while maintaining significant patterns; transforms correlated variables into uncorrelated principal components (PCs); no labels needed
PCA Goal:: Variance maximization :: Projects data onto K orthogonal axes (principal components) while MAXIMIZING the variance of the data in the lower-dimensional space; PCA converts correlated features into uncorrelated features
Why Use PCA:: Practical benefits :: Visualize high-dimensional data (100 features -> 2 or 3 dims), speed up ML models by removing unnecessary features, remove redundancy of correlated features
PCA Math Sketch:: Input, output, and why it works :: Input: correlated features X. Output: uncorrelated components Z = X*W where W = eigenvectors of X^T X. Eigenvectors = directions of max variance; eigenvalues = amount of variance retained
PCs as Linear Combinations:: Formula for principal components :: PC1 = v11*X1 + v12*X2 + v13*X3, PC2 = v21*X1 + ..., each PC is a linear combination of the original features; PC1 captures most variance, PC2 is orthogonal to PC1 with second-most, PC3 orthogonal to both
Loadings:: What the coefficients v_ij mean :: The eigenvector components (e.g. v1 = [0.5, 0.5, 0.707]) are called loadings: they show how much each original feature contributes to that principal component
PCA 5 Steps:: The step-by-step recipe :: 1) Standardize the data (mean 0, variance 1), 2) Compute the covariance matrix, 3) Calculate eigenvectors and eigenvalues of it, 4) Sort PCs by eigenvalues (highest = most important) and keep top k, 5) Project the data onto the selected PCs
Standardization:: Why PCA requires it :: PCA is affected by feature scale (height in cm vs weight in kg); standardizing to mean 0 and std 1 ensures all features contribute equally
Covariance Matrix:: What its entries mean :: Diagonal = variance of each feature (spread); off-diagonal cov(xi,xj) = how feature pairs vary together: positive = increase together, negative = one up one down, zero = no linear relationship; it reveals the directions where data varies most
Sigma v = lambda v:: Eigenproblem in PCA :: Solve covariance*eigenvector = eigenvalue*eigenvector: eigenvector v = direction of a principal component (max variance), eigenvalue lambda = scalar importance (variance along that direction); PCs sorted by lambda, biggest first
Choosing k:: Strategies for how many PCs to keep :: Keep PCs collectively capturing most variance: retain >95% cumulative variance, Kaiser's rule (keep lambda >= 1), elbow method on a scree plot, or just 2-3 PCs for visualization
Explained Variance Ratio:: Definition and example :: EVR = eigenvalue / sum of all eigenvalues: variance one PC explains; e.g. eigenvalues 5,3,2 (total 10) give EVR 0.50, 0.30, 0.20; larger EVR = component captures more important information
Cumulative Explained Variance:: Definition and use for k :: CEV = sum of EVRs of the first k PCs (0.50, 0.80, 1.00 in the example); tells total information retained by top k PCs; if threshold = 80%, keep the top 2 PCs
Transforming the Data:: Final projection step :: X_reduced = X_standardized * Wk where Wk is the matrix of the top k eigenvectors (one per column); e.g. 10 features -> 2 features, each column a PC, most variance retained
PCA Why It Works:: Ordering of the components :: 1st PC = direction of max variance; each next PC is orthogonal to the previous ones and captures the most remaining variance; pipeline: Data -> covariance -> eigenvectors -> sorted PCs -> reduced data
PCA Benefits:: The upsides :: Dimension reduction retaining essential info, noise reduction, feature transformation into orthogonal components revealing hidden patterns, 2D/3D visualization, indirect feature selection via PC ranking
PCA Downsides:: The limitations :: Linearity (assumes straight-line relationships), interpretability (PCs hard to explain in terms of original features), loss of information (prioritizes variance, may drop important details), no feature learning (works only with what is already there)
Key Takeaway PCA:: One-line summary :: PCA finds new axes (PCs) where the data varies most: eigenvectors = directions, eigenvalues = importance; project data onto the top PCs to reduce dimensions -- great for preprocessing, noise reduction, and exploration
