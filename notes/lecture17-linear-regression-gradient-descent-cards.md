Modular ML Design:: The 3 modules for designing an ML algorithm :: 1) Choose a model (relationship between variables), 2) Define a loss function (how bad the fit is), 3) Fit & optimize (minimize loss via an optimization algorithm, with constraints/penalties); mixing and matching modules creates new ML methods
Regression vs Classification:: Core difference in output type :: Classification predicts discrete mutually exclusive categories (spam or not); regression predicts continuous real-valued numbers (what will this home sell for?) -- "which category?" vs "how much?"
Linear Regression:: Definition and key assumption :: Supervised algorithm predicting a continuous target Y as a linear combination of features X and weights; assumes a direct linear relationship between X and Y
Simple Linear Regression:: Model equation and terms :: y_hat = b0 + b1*x; b1 is the slope (weight on the single feature), b0 is the intercept (y-value when x = 0); fit a line to predict a continuous dependent variable from an independent one
Slope and Intercept:: Interpretation of each coefficient :: Slope b1 = how much Y changes for every 1-unit increase in X (steepness); intercept b0 = starting value of Y where the line crosses the y-axis when X is 0
Multiple Linear Regression:: Model with P features :: y_hat = b0 + b1*x1 + b2*x2 + ... + bP*xP; xi are features, bi are model parameters/coefficients, Y is the target variable
Line of Best Fit:: What makes a line the "best fit" line :: The straight line with the least possible overall error among all straight lines: fits the data well, minimizes prediction errors, captures the relationship; found by choosing best b0 and b1
Residual:: Definition and formula :: e = Y - y_hat, the difference between actual and predicted value; good models have small residuals on average
Loss vs SSE vs Cost:: Hierarchy of error measures :: Per-point loss = (Y - y_hat)^2 (squared error penalizes big errors); SSE/RSS/SSR = sum of squared errors over all points; cost function = MSE = SSE/n = (1/n) * sum (Y - y_hat)^2, normalized for dataset size
Optimization Problem:: Why fitting linear regression is an optimization problem :: The cost function (MSE) must be minimized over b0 and b1 to get the best-fit line; solved via Ordinary Least Squares (OLS) or Gradient Descent
Gradient Descent:: What it is and the 3-step loop :: Iterative optimization that adjusts b0 and b1: 1) compute the gradient (partial derivatives of cost w.r.t. each parameter), 2) update parameters in the OPPOSITE direction of the gradient, 3) repeat until convergence (cost stops decreasing significantly)
The Gradient:: Key concept definition :: A vector indicating the direction and steepness of the slope of the function at a point; it points uphill, so gradient descent walks downhill (opposite it)
Gradient Descent Steps:: The 4-step process :: 01 initialize b0/b1, 02 calculate the cost (RSS or MSE), 03 adjust parameters along the gradient, 04 repeat iterations until minimum cost is achieved
Learning Rate:: Role of alpha and failure modes :: alpha is the step size in the update b -> b - alpha * gradient; too large overshoots the minimum and may fail to converge; too small converges slowly with too many iterations
Learning Rate:: Common values :: 0.001, 0.003, 0.01, 0.03, 0.1, 0.3
L.I.N.E.:: The 4 key assumptions of linear regression :: Linear relationship between X and Y; Independent residuals; Normal (normally distributed) residuals; Equal variance of residuals (homoscedasticity) -- assumptions must be checked for valid results
R-squared:: Definition and interpretation :: Coefficient of determination: how much of the variance in Y the model explains; range 0 to 1, higher better; R2 = 0.85 means 85% of variance in Y explained by X; R2 = 0 is as good as guessing the mean, R2 = 1 is perfect; computed from SSres/SSE over SStot
RMSE:: Why use RMSE instead of MSE :: RMSE = square root of MSE, so it is in the same/original units as Y and easier to interpret (RMSE = $10K means predictions are +/- $10K on average); lower is better
MAE:: Strength and weakness of mean absolute error :: Average of absolute prediction errors; less sensitive to large errors than MSE/RMSE (may hide high-risk mistakes); lower is better; non-differentiable at zero, so less ideal for gradient-based optimizers
Polynomial Regression:: What it adds and its risk :: Extends linear regression with polynomial terms (x^2, x^3) to fit curved nonlinear patterns (U-shapes, S-curves); more flexible but prone to overfitting -- generally use only small degrees
Ridge vs Lasso:: L2 vs L1 penalty behavior :: Ridge (L2) penalizes squared weights: shrinks coefficients but never to zero; best with multicollinearity (correlated predictors) and many small/medium features. Lasso (L1) penalizes absolute weights: forces some coefficients to 0 = feature selection, sparse interpretable models, good with many irrelevant features
Elastic Net:: What it combines :: Ridge + Lasso in one loss: handles correlated features AND does feature selection; preferred when the dataset has many correlated features
Regularization Lambda:: Choosing the penalty strength :: Too large lambda -> underfitting; too small -> overfitting; select via cross-validation, grid/random search, or automated tools like scikit-learn RidgeCV / LassoCV
Random Forest Regression:: How it works and why it is popular :: Ensemble of decision trees built on random subsets; each tree predicts independently and the final output is the AVERAGE of all tree predictions; handles nonlinearity, robust to outliers/overfitting, works with many features -- often the go-to regression in practice
Regression Metrics Summary:: The 4 evaluation metrics to know :: R2 (variance explained, 0-1, higher better), MSE (average squared error, penalizes big errors, lower better), RMSE (sqrt of MSE, original units, lower better), MAE (average absolute error, robust to outliers, lower better)
